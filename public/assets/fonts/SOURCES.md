# Self-hosted display fonts

Active font: Noto Sans SC variable, sourced from the locally installed `C:/Windows/Fonts/NotoSansSC-VF.ttf`. SIL Open Font License in NotoSansSC-OFL.txt. Subset to current site text and ASCII with scripts/build-display-font.py; glyph shapes unchanged. Font weights 100-900. Future missing characters fall back to system sans-serif. Upstream: https://github.com/google/fonts/tree/main/ofl/notosanssc

The following earlier fonts are retained as assets but are no longer used by the site:

Anton: https://github.com/google/fonts/tree/main/ofl/anton
